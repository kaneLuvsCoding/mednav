Issue 2 — Ranking Algorithm က Static ဖြစ်နေတယ်
P1 — Major improvement
rules.py မှာ ဒီ Formula ကို သုံးထားပါတယ်။
\[
Score = I - 0.5T - 0.5R
\]

- \(I\) = Information value
- \(T\) = Time cost
- \(R\) = Resource cost
ဒါပေမယ့် ဒီ Values တွေက Fixed ဖြစ်နေပါတယ်။

ဥပမာ Blood Pressure Measurement ရဲ့ information value က 5 ဖြစ်ပြီး Symptom Review က 3 ဖြစ်ပါတယ်။ Astronaut တစ်ယောက်ချင်းစီရဲ့ Missing Information နဲ့ Investigation Context အပေါ်မူတည်ပြီး Value တွေ ပြောင်းလဲခြင်း မရှိပါဘူး။

ကျွန်တော် အကြံပြုချင်တာက Context-Aware Information Ranking ပါ။

ဥပမာ—
- BP data မရှိရင် BP check ရဲ့ information priority တိုးနိုင်တယ်။
- BP data ရှိပြီးသားဆိုရင် repeat measurement ကို အမြဲ ဦးစားမပေးသင့်ဘူး။
- Equipment မရှိရင် ranking မလုပ်ခင် exclude လုပ်ရမယ်။
- Emergency Override ရှိရင် ranking ကို လုံးဝကျော်ရမယ်။
- Data provenance မယုံကြည်ရရင် reliable information ရရှိမယ့် check ကို ဦးစားပေးဖို့ စဉ်းစားနိုင်တယ်။
